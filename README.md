# Flutter Task Reminder App

A mobile application to help UMSU students manage assignment deadlines. Built as a final project for Information Technology.

## ✨ Features
- Add, Edit, Delete Tasks
- Calendar view for deadlines
- Chart page for task progress
- Local Notifications reminder
- Detail page & local database (db_helper)

## 🛠️ Tech Stack
- Flutter / Dart
- SQLite (db_helper)
- flutter_local_notifications (notif_services)

## 📂 Project Structure
lib/
- main.dart
- database/db_helper.dart
- pages/add_page, calendar_page, chart_page, etc.
- services/notif_services.dart
